# סיכומי שינויים לפי מסלול

כשעובדים בכמה סשנים במקביל, כולם רוצים לעדכן את `docs/PROJECT-SUMMARY.md` —
וזו התנגשות מובטחת בכל סבב.

לכן: כל מסלול כותב **קובץ חדש משלו** כאן (`track-a.md`, `track-b.md` …) עם סיכום
מה נבנה, החלטות שהתקבלו, ומה נשאר פתוח. אחרי המיזוג הכל מתקפל לתוך
`PROJECT-SUMMARY.md` והקבצים כאן נמחקים.

גם דברים שראיתם ולא תיקנתם כי הם מחוץ לבעלות שלכם — לכאן.
